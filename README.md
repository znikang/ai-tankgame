# Tank Wars

多人線上坦克射擊遊戲 — 佔領據點、拾取武器、擊毀敵人！

## 功能特色

- **即時多人對戰** — 透過 Socket.IO 連線，支援多名玩家同時遊玩
- **5 個據點佔領系統** — 在據點範圍內停滯即可佔領，全部佔領即獲勝
- **5 種武器** — 基礎武器、散彈槍、狙擊槍、冰凍槍、加速彈
- **AI 敵人** — 3 台 AI 坦克巡邏防守據點
- **5 張地圖輪換** — 廢墟戰場、冰封要塞、熔岩裂谷、叢林迷宮、霓虹都市
- **地震系統** — 隨機地震會移動可破壞的牆壁
- **帳號系統** — 註冊/登入、個人統計、排行榜
- **視覺特效** — 爆炸粒子、擊殺飄字、據點進度環、領土覆蓋

## 技術架構

| 層級 | 技術 |
|---|---|
| 伺服器 | Node.js + Express + Socket.IO |
| 快取/狀態 | Redis |
| 客戶端 | HTML5 Canvas + Vanilla JS |
| 容器化 | Docker + Docker Compose |

## 快速開始

### 前置條件

- [Docker](https://www.docker.com/) & [Docker Compose](https://docs.docker.com/compose/)

### 啟動遊戲

```bash
cd tank-multiplayer
docker compose up -d
```

這會同時啟動：
- **tank** — 遊戲伺服器（Port 3000）
- **redis** — Redis 快取（內部網路，資料持久化）

### 開啟遊戲

瀏覽器前往：`http://localhost:3000`

### 停止遊戲

```bash
docker compose down
```

### 重新建構（修改程式後）

```bash
docker compose up -d --build
```

## 遊玩方式

### 移動控制

| 按鍵 | 動作 |
|---|---|
| **W** | 前進 |
| **S** | 後退 |
| **A** | 左轉 |
| **D** | 右轉 |
| **空白鍵** | 開火 |

### 遊戲目標

1. **佔領據點** — 駕駛坦克進入據點範圍並保持靜止，5 秒後據點變為你的顏色
2. **全佔領勝利** — 當 5 個據點全部被你方控制時，獲得 +500 分並切換下一張地圖
3. **擊毀敵人** — 射擊敵方坦克或 AI 會掉落武器或血量補給
4. **拾取道具** — 開坦克壓過地上的道具即可拾取

### 武器說明

| 武器 | 顏色 | 說明 |
|---|---|---|
| 基礎武器 | 黃色 | 標準射速與傷害 |
| 散彈槍 | 橘色 | 一次射出 5 發子彈，扇形散射 |
| 狙擊槍 | 紅色 | 高傷害、高射速、子彈速度快 |
| 冰凍槍 | 青色 | 使敵人移動速度減半 |
| 加速彈 | 綠色 | 子彈速度極快 |

### 掉落物

- **武器** — 擊殺敵人後隨機掉落一種特殊武器
- **血量補給** — 50% 機率掉落，恢復 30 HP（上限 100）

## 開發者資訊

### 本地開發（不使用 Docker）

```bash
# 啟動本機 Redis
redis-server

# 啟動伺服器
cd tank-multiplayer
npm install
npm start
```

### 專案結構

```
tank-multiplayer/
├── server.js              # 遊戲伺服器（邏輯、Socket.IO、Redis）
├── public/
│   ├── index.html         # 遊戲客戶端頁面
│   └── client.js          # 客戶端遊戲邏輯 + Canvas 渲染
├── docs/                  # 開發文件與計畫
├── Dockerfile             # 容器映像
├── docker-compose.yml     # 雙服務器設定
└── .dockerignore
```

### 預設設定

| 項目 | 值 |
|---|---|
| 伺服器 Port | 3000 |
| 地圖大小 | 1600 × 1200 |
| AI 數量 | 3 |
| 佔領時間 | 5 秒 |
| 地震間隔 | 30–90 秒隨機 |
